# Private workspace (not in git)

Copy this folder to the repo root as `internal/` for notes that stay on your machine only:

```text
internal/
  video-shoot/     # shot list, B-roll notes, take logs
  study/           # subject contact notes (use IDs only in data/)
  scripts/         # one-off experiments
```

Everything under `internal/` is listed in `.gitignore` and will not be pushed to GitHub.

Public documentation: `README.md`, `docs/STUDY_PROTOCOL.md`, `docs/FAILURE_MODES.md`.
